# Data boundaries / consent

## 3層を混ぜない

1. **顧客の手帳**：出生情報、占い結果、相談・出来事・自由文の感想。顧客のAIとGoogle Sheetsで管理。当社は保存もGoogleアクセスも行わない。
2. **運用に必要なデータ**：Auth情報、契約、割当量、90日リクエスト台帳、アカウント期間中の初回利用日時。GoogleログインではSupabase Auth自体が基本プロフィールを保有するため「個人情報を一切持たない」と宣伝しない。
3. **任意の改善計測**：funnel、固定ラベル評価、本人が指定したtopic。`PRODUCT_ANALYTICS_ENABLED`＋本人選択。topicはさらに別のinterest選択。

サービスが計算入力を一時的に受け取ることはある。「保存しない」と「受け取らない」を分けて通知する。HMACfingerprintは鍵なしでは照合困難だが、当社が再計算できる仮名化データとして扱う。

## 前案から採用しないもの

- 自由文のreading_feedback、個人的な悩みの推測、自動プロファイリング。
- 顧客側ChatGPT/Claudeのトークン・金額を0と置くこと。
- 自社が見ていないGoogle Sheetsの書込成功イベント。
- 未同意の匿名visitor/cookie跨ぎの追跡、IP/User-Agent全文、参照元URL全文。
- 競合の価格・成長数字から自社スキーマや購買意向を確定したと言うこと。

## 流入と観測源

署名リンクは公開post UUIDと期限だけを含み、人を追跡するIDは含まない。ログイン後、本人が任意計測に同意した場合だけ投稿との関係を保存する。リンクの共有・途中離脱・未同意・OAuth途中のref消失では不明が残る。

登録時の本人申告と、MCPを使っているクライアントは異なる証拠。ChatGPTで動作したからChatGPTで発見されたと推定しない。接続clientは別イベントに記録する。

## 削除とエクスポート

ログイン画面内に任意設定・エクスポート・削除だけを置く。管理ダッシュボードは作らない。

- 同意撤回：任意イベントとfeedback削除、topicをNULL。通常の計算を止めない。
- エクスポート：本人認証、resource allowlist、100件ページ、asOf固定、nextOffset。fingerprint／秘密値は返さない。並行削除によりページが変わり得るので厳密snapshot exportは将来必要時に追加する。
- アカウント削除：課金の解約を先に確認。利用停止→セッション失効→Auth削除、CASCADEで製品履歴削除。顧客Googleファイルは削除しない。課金外部IDは承認された保持方針に従う。
- モデルへ自由文を送らなくても、Vercelや認証プロバイダーのログが残る可能性はある。リクエストbodyログ・エラー全文を無効にし、リダイレクトquery/トークンの記録を確認する。

この文書は実装方針であり、全法域の法務審査済み宣言ではない。プライバシー通知、委託先、保存国、権利対応の連絡先を公開前に決める。
